# Linkbreakers Homebrew tap

```bash
brew install linkbreakers-com/tap/linkbreakers
```

Installs the [Linkbreakers CLI](https://github.com/linkbreakers-com/linkbreakers-cli) (`linkbreakers`) on macOS and Linux. Upgrade with `brew upgrade linkbreakers`.

Casks in `Casks/` are published automatically by GoReleaser on every CLI release. Do not edit them by hand.

Docs: https://linkbreakers.com/cli
